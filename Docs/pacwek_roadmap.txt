
PACWEK ADDON ROADMAP
====================

Project:
--------
Pacwek - WoW 3.3.5a / Warmane oriented loot addon

Goal:
-----
Single-master-looter focused loot system for WotLK raids with:
- SoftRes support
- HR support
- MS/OS/TMOG rolling
- Automatic loot handling
- Lightweight architecture
- No addon synchronization required

Design Philosophy:
------------------
- Optimized specifically for Warmane / Trinity-like cores
- Stable > Feature bloat
- ML-centric workflow
- Fast raid UX
- Minimal chat spam
- No GDKP support
- No officer sync
- No distributed state/network layer


==================================================
CURRENTLY IMPLEMENTED
==================================================

[CORE]
- Ace3 addon initialization
- WoW 3.3.5a compatibility layer
- SavedVariables support
- Slash commands:
    /pacwek
    /pw
    /pwsr
    /pwtest

[UI]
- Main import window
- ESC close support
- Auto-close after import
- Draggable frame
- Scrollable multiline import field

[SOFTRES]
- CSV import from softres.it
- Proper CSV parsing with quoted item names
- Duplicate reservation support
- Persistent database storage
- Reservation lookup system

[ROLL ENGINE]
- SR/MS/OS/TMOG logic
- Roll parsing:
    /roll      -> SR/MS
    /roll 99   -> OS
    /roll 98   -> TMOG/GREED

- Priority:
    SR > MS > OS > TMOG

- Duplicate roll protection
- Multi-SR support
- Tie/reroll system
- Automatic winner resolution
- Invalid roll filtering
- Reserved item protection
- Duplicate item roll support

----------------------------

- Early finish system
- Duplicate item rolling
- Multiple winner resolution
- Countdown warnings

- If item has SR:
    only SR rolls accepted
